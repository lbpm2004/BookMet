# BookMet
📚 Proyecto de la materia Sistemas de Información
Se propone el desarrollo de un Sistema Web y Móvil de Intercambio de Libros para la comunidad de la Universidad Metropolitana. El objetivo principal es
proporcionar una plataforma centralizada que permita a los estudiantes y docentes publicar,
buscar y gestionar el intercambio o venta de recursos educativos de manera eficiente.

🏅 Fase 1 Concepción (Hito 1): Esta fase inicial tiene como objetivo definir el alcance del proyecto,
identificar a los stakeholders y obtener una visión clara de lo que se va a construir. Consultar el documento Google Docs para más detalles.
